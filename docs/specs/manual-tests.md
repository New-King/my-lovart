# 手测清单（当前阶段）

> 用途：把“必须真人点一遍”的项集中在这里；脚本能覆盖的不要手测。每次手测后把结论写回本文或对应 note，不要只留在聊天里。
> 最后更新：2026-11-17，对应 Phase 2b 收尾。

## 测试前

1. `pnpm dev` 同时起 web（3000）和 server（3001）；确认 `/health` 的 `pid / startedAt` 与当前进程一致，避免打到旧进程。
2. 登录后新建一个空项目专门用来测，失败也不污染正式项目。
3. 出问题时保留 `.traces/` 最新 JSONL，并在本文记录时间点、项目名、消息 id。

## T0 素材库刷新回归（G42）

1. 打开画布工具栏“素材库”，上传 1-3 张图片。
2. 刷新页面，再打开素材库：刚上传的图仍在“素材库”区域（不是公共素材）。
3. 点一张加入对话，发一句“按这张图做张海报”，确认模型能看到图。
4. 删除其中一张，刷新后不再出现；旧 `/files/:id` 链接应 404。
5. 失败记录：浏览器 console、`GET /materials` 返回、服务端 Storage 日志。

## T1 插入图片到画布（回归）

以前报过“选完图片、点打开，画布没反应”。

1. 空画布点工具栏“图片”，选一张本地 PNG/JPG。
2. 期望：图片出现在画布中心附近，顶部状态短暂显示“保存中…”后变“已保存”；缩略图和画布文件都能在刷新后恢复。
3. 再选 2 张：按批次横排，不叠在一起。
4. 失败记录：浏览器 console、`.traces` 里该轮的 `canvas.sync` / 保存事件。

## T2 视频落画布并播放（G28）

1. 新项目里发起一条 5 秒视频（可以直接说“5 秒，直接出片不用确认”，但要知道这会跳过前期确认）。
2. 等待期间工具行应持续显示阶段/百分比，不是一直“渲染中”。
3. 成功后期望：对话里出现视频卡片可播放；画布出现同一视频的 embeddable 元素，悬停/点击播放，移出暂停；元素位置不压住已有图片。
4. 刷新页面：视频仍能播放（链接是 `/files/:id`，支持 Range）。
5. 失败记录：job 状态（`GET /workspace/:projectId/jobs/:jobId`）、video 元素 customData、network 面板的 Range 响应。

## T3 生成中取消（G29）

1. 发起一条 10 秒视频或一张 2K 图。
2. 工具行出现后点输入端“停止”。
3. 期望：消息变“已取消”；job 变 `canceled`；worker 调 provider abort；稍后不再冒出新资产、不再往画布插图；不会变成 `failed`。
4. 再发一条新消息：队列继续可用，不卡在 running。
5. 失败记录：job 表状态、trace 里 `job.cancel` / `run.canceled`。

## T4 真实 Pexels 灵感搜索（G40/G41）

前置：把 `PEXELS_API_KEY=...` 填进 `my-lovart/.env.local`，重启 server。

1. 新项目输入“想给白色保温杯做条短视频，风格还没想好，先找几组参考方向”。
2. 期望：2-3 组真实照片卡片，组标题是中文方向名；本轮不出图、不出视频、不说“已生成到画布”。
3. 点某张图左上角箭头“加入对话”，发送“按这张的感觉做一张 16:9 概念图”。
4. 再测文字路径：新开一轮，回复“第 2 组第 1 张那种感觉”，期望 Agent 不重新搜图，直接用该图作参考出概念图。
5. 失败记录：`search_inspiration` 工具输出、Pexels 返回码、最终 generate_image 的 `inputImages`。

## T5 视频前期 strict 分支（需要真实产品实拍）

前置：准备同一只保温杯的 3-4 张实拍（闭盖正面/侧面、开盖内部/螺纹）。

1. 上传实拍，要求“产品必须和实拍一致”，做 10 秒视频。
2. 期望：选择 strict；产品锚图以实拍为参考；开盖/内胆镜头先要细节锚图；第 1 镜出片后服务端抽实际末帧，第 2 镜首帧承接它；停在视频前。
3. 禁止：无实拍也能过 strict；把生成图说成“和实物一致”；开盖状态凭空发明螺纹。
4. 失败记录：canon/shot 的 `sourceAssetIds`、`video_last_frame` 资产、对应 M26/M27 的复现条件。

## T6 角色图单镜头 image-to-video（G43）

1. 上传一张人物/角色图，输入“生成 5 秒的视频，让这个人物站起来向我靠近”。
2. 期望：Agent 直接提交视频（`inputImages` 就是这张图），不生成角色设定图、不出首尾帧、不建分镜；比例从图推断。
3. 如果视频渠道没配，回复应说明缺渠道，而不是改走“先做角色设定图”。
4. 失败记录：工具调用列表（`generate_video` vs `generate_image`）、最终 `inputImages`。

## T7 多镜头 + 参考图（referenceDirect，G44）

1. 上传一张角色或产品参考图，输入“做一条 10 秒、两个镜头的短片，角色/产品要和这张图一致”。
2. 期望：登记该图为 canon；建 2 镜分镜并设 `referenceDirect`；不生成角色设定图、不生成关键帧/尾帧。
3. 第一镜直接用参考图出片；第二镜服务端自动用第一镜实际末帧作首帧，不需要用户再确认关键帧。
4. 只有两镜角度差异极大、单张图约束不住时，才允许关掉 referenceDirect 生成关键帧。
5. 失败记录：`register_reference` 输出、storyboard metadata、每镜 generate_video 的 inputImages。

## T8 锚图确认后批量做完分镜图（G46）

1. 10 秒 2 镜广告，先答完需求、确认产品/角色设定图。
2. 回复“设定图可以，继续”。
3. 期望：一次生成 2 镜的首帧和尾帧（共 3-4 张图），中间不逐张问；全部完成后给完整脚本方案，只问一次“按这个顺序出片吗？”。
4. 回复“可以，开始出片”：直接进入视频，不重新生成分镜图；第 1 镜出片后第 2 镜自动接实际末帧。
5. 失败记录：每轮工具列表、分镜 `first_frame_asset_id/end_frame_asset_id`、视频 `inputImages`。

## T9 所有聊天图片一键加入对话（G47）

1. 在对话里找到：一张生成图、多图横排中的一张、自己消息里上传的图片。
2. 鼠标移上去（移动端直接显示）：左上角出现和灵感卡片一样的箭头。
3. 点箭头：输入框出现该图附件 + “已加入对话框”toast；不会触发查看大图/下载/放入画布。
4. 发一句“按这张图再改一版”，确认模型能读到图。
5. 失败记录：图片类型、按钮是否被其他层遮挡、console 报错。
