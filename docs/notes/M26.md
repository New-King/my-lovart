# M26 · 真实 5 秒保温杯前期验证

## 测试条件

- 临时项目，5 秒、9:16、单镜头、日系冷白+浅木色；
- 产品输入图：用户之前项目里的“米白直筒杯 / 原木平盖”那张首帧；
- 流程：真实模型 + Seedream 生图作业，停在视频生成前；测完项目已删除；
- 产物：`verification/video-consistency-2026-11-16/`（`index.html` 是汇总页）。

## 发现并修复的 bug

第一轮锚图生成成功，但第二轮关键帧连续两次 400：

```
Volces 返回 400：Error while downloading:
http://127.0.0.1:3001/files/<id> ... connection refused
```

原因：锚图和首尾帧的本地 `/files` URL 直接塞给了 provider；provider 访问不到用户本机。`resolveReferences` 只转 explicit 输入，没转锚图/衔接帧。已修复：

- 锚图、上一镜实际末帧、当前首帧、视频首尾帧在传给 provider 前统一走 `fileDataUrlFromUrl()`；
- 本地文件转为 data URL，外部 URL 原样保留；
- 修复后关键帧/尾帧正常生成，`sourceAssetIds` 仍记录真实资产 id。

## 逐张结论

| 图片 | 结果 | 说明 |
| --- | --- | --- |
| 主视觉锚图 | 合格 | 故意不含产品，只定冷白墙、浅木台面、侧逆光和留白 |
| 产品锚图 | 合格 | 与输入实拍一致：米白直筒杯身、原木平盖、窄接缝、比例接近 |
| 首帧 v1 | 合格 | 同一只杯子，闭盖、热气从盖缝升起，构图成立 |
| 尾帧 v1 | 合格 | 同一只杯子，机位/台面/光影连续，只增加杯壁凝露 |
| 首帧 v2 | **不合格** | 要求“开盖+低机位”后，杯身变宽变矮，出现螺纹口、盖内白色塑料圈和黑胶圈，是模型新发明的结构 |
| 尾帧 v2 | 自身一致，身份不合格 | 和 v2 首帧能接上，但同样不是产品锚图那只杯子 |

结论：**闭盖镜头的一致性通过；开盖镜头失败**。不是首尾帧衔接的问题，而是“开盖状态”在用户实拍里没有定义，模型只能按常识发明螺纹口/内盖。

## 结论与下一步

1. 产品锚图只覆盖“闭盖外观”。开盖、内部、螺纹等状态必须补对应实拍，或者在脚本上避免未拍摄过的状态。
2. 如果用户坚持开盖，正确做法是补一组“开盖产品锚图”（从实拍或已有视频截帧），不要只靠 closed-lid canon。
3. 生成后视觉一致性校验（文档里的 P2 `keyframe_drift`）仍有必要：v2 这种漂移靠血缘校验发现不了，只能靠视觉比对。
4. 多镜头按镜序闭环、实际末帧衔接的代码链路本轮没有触发视频生成，但 `verify-video-guard/frame` 已覆盖门禁和抽帧逻辑。
