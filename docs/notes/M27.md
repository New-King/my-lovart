# M27 · 开盖/内部状态不能靠闭盖锚图猜

## 现象

用户看真实测试图后指出：杯子从高到矮，比例不一致。逐张对照：

- 产品锚图、v1 首尾帧是同一只高直筒杯；
- v2 开盖首尾帧变成更矮更宽的罐形，出现螺纹口、盖内白色塑料圈、黑胶圈；
- 即使把 v1 已确认首帧放在参考图第一位重新生成（07 号图），杯身仍然变矮变宽。

说明 Seedream 的多图参考不是身份锁定：当 prompt 要求“开盖/螺纹”这类参考图里没有定义的状态时，模型会优先发明该状态的几何结构，顺带改掉整体比例。

## 结论

- 闭盖镜头：canon + 当前首帧能保持产品一致；
- 开盖/内胆/倒水：仅靠闭盖实拍 + “保持比例”的 prompt 不够，必须补**状态细节实拍**，否则不应出关键帧。

## 实现

1. 新增 `product_detail` 锚图类型（migration `0013`：`storyboards.product_detail_anchor_asset_id`）。
   - `generate_image({role:"canon", anchorType:"product_detail"})` 必须传对应实拍，没有返回 `detail_photo_required`。
   - 关键帧参考图变为：当前已确认首帧 → 产品锚 → 细节锚 → 衔接帧，最多 4 张。
2. 新增状态守卫：
   - 镜头标题/描述/prompt 或本次生成 prompt 命中 `开盖|打开|拧开|螺纹|内胆|杯口内部|盖内|倒水|出水`，但分镜没有 `productDetailAnchorAssetId`，返回 `product_state_reference_required`，并提示上传开盖/内壁/螺纹实拍。
3. 重做同一镜首帧时，自动把当前已确认首帧放在参考图第一位，只改机位/动作，不再从零文生图。
4. 系统提示同步：开盖/内部/倒水必须先要细节实拍，不能靠模型猜。

## 验收

`verify:video-guard` 24/24：新增

- 没有细节实拍 → `detail_photo_required`
- 开盖关键帧但缺细节锚图 → `product_state_reference_required`
- 有细节锚图后开盖关键帧放行，且参考图包含细节锚
- 重做同一镜首帧时当前首帧是第一参考

server/web typecheck 0。

## 还缺什么

- 真实用户的开盖/内壁/螺纹实拍，才能验证开盖镜头是否真的锁住；
- P2 视觉一致性校验（`keyframe_drift`）仍未做：它可以拦“血缘正确但比例变了”的图，是下一道保险。

> 2026-11-16 更新：这里的“必须有实拍”现在只在 `strict` 策略下强制；`adaptive` 允许基于产品设定图生成细节锚草案，`loose` 可跳过。见 `docs/notes/M29.md`。
