# M24 · 视频连贯性：多锚点、首尾帧链、执行级镜头包

## 背景

M23 解决了“先有产品锚图、关键帧必须引用它”，但只有一个 canon，且多镜头之间没有衔接。用户追问：分镜图之间必须连贯，产品要一致，还要和脚本对得上。

## 参考审计

`Video_Remix_Benlai/无限画布-生成视频对话参考.txt`：以分镜图作为首帧逐镜生成，4 秒最小单位，逐条确认。真正关键的是同项目的制作级规格：

- 锚图组 3-5 张：角色 / 场景 / 产品 / 主视觉，按 brief 动态规划；
- 每镜执行字段：`continuity_note`、`reference_bindings`、`must_have`、`negative`、`start/end_state`；
- 上一段完成后，下一段提示词显式延续上一段最后画面；上一镜末帧可作为下一镜输入；
- 展示层与执行层分离，执行前有放行检查；
- 一致性拆成静态、镜头内、段落三层。

Lavart 没有这些；它只有首帧/尾帧上传和最多 7 张参考图，不能解决产品漂移和镜头断裂。

## 实现

### 锚图组

migration `0011`（已执行）：

- `storyboards.character_anchor_asset_id` / `scene_anchor_asset_id` / `style_anchor_asset_id`
- `canon_asset_id` 作为产品锚
- `storyboard_shots.scene_goal` / `continuity_note` / `negative_prompt`

`generate_image({role:"canon", anchorType})` 支持 product / character / scene / style；产品锚必需，其他按 brief 动态生成，不固定 4 张。没有人物就不生成角色锚。

关键帧自动引用该分镜所有有效锚图（product → character → scene → style），最多种 4 张，保证产品、场景、色调同时稳定。

### 首尾帧链

多镜头按顺序：

1. 镜头 1 首帧：锚图组；
2. 镜头 1 尾帧：锚图组 + 镜头 1 首帧；
3. 镜头 2 首帧：锚图组 + 镜头 1 尾帧（服务端自动加参考，并写入 `sourceAssetIds`）；
4. 镜头 2 尾帧：锚图组 + 镜头 2 首帧；
5. 每条视频用该镜头首/尾帧作为 MiniMax 首帧/尾帧输入，剪辑点两端画面一致。

预检新增：

- 非收尾镜头缺尾帧 → `end_frame_required`
- 下一镜首帧没有承接上一镜尾帧 → `continuity_not_anchored`
- 上一镜缺尾帧 → 生成下一镜首帧时 `previous_end_frame_required`

### 执行字段

`create_storyboard` / `update_shot` 支持 `sceneGoal`、`continuityNote`、`negativePrompt`；`get_storyboard` 和 `<project_state>` 返回这些字段和首尾帧/成片指针。视频时长、首尾帧由服务端锁定，模型不能临时换图。

## 验收

`verify:video-guard` 17/17 通过，不调用 provider：

- 5 秒 1 镜/10 秒 2 镜、概念板不能直接转视频；
- 缺产品锚拒绝关键帧；
- 首帧必须有产品锚血缘；
- 多镜头首镜缺尾帧拒绝；
- 下一镜首帧自动带上一镜尾帧参考；
- 没承接尾帧的首帧拒绝；
- 两镜首尾帧接通后放行；生成 prompt 自动带镜头职责和衔接。

server/web typecheck 0。

## API 边界

MiniMax H3 文档（`video-generation-v2-create`）确认：

- H3 / Highspeed / Lite 支持 4-15 秒，Max 支持 5-15 秒；
- 图生视频首帧/尾帧与多模态参考（reference_image/video/audio）**互斥**，不能在同一请求里混用；
- 首帧 ≤1、尾帧 ≤1，多模态参考图 ≤9。

因此一致性不能靠“生成视频时再塞一堆参考图”，必须把产品/场景信息提前固化到首尾帧里；这正是我们采用锚图组 → 首尾帧 → 图生视频链路的原因。4 秒下限也解释了为什么要按总时长反推镜头数。

## 仍未实现

- 多镜头拼接成片。当前每个镜头独立生成 clip，不会假装合成完整时间线。用户明确说拼接不重要，先保证连贯和产品一致。
- 锚图目前按分镜全局共享；多场景、多角色的长片后续需要“镜头 → 锚图绑定”粒度，避免把 A 场景锚套到 B 场景。
