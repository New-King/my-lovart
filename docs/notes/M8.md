# M8 · 历史参考图保留

## 做了什么

- 每次运行除了本轮附件，还会收集最近几轮用户发过的图片（最多 8 张，按 URL 去重），一起注入 `<input_images>`
- 提示词明确区分：`<input_images>` 是对话里发过的参考图，画布为空也仍然可用；`<canvas_state>` / `<canvas_images>` 才是画布内容
- 修掉了「用户发了图 → 下一轮说加点元素 → Agent 查画布为空 → 让用户重新上传」的失忆

## 为什么

附件原来只存在于发送那一轮；下一轮只有历史文字，没有附件数据。用户说「加点过年元素」时，画布确实是空的，模型就误判参考图也不存在。参考图属于对话资产，不应该因为换了一轮就丢失。

## 已知问题

- 只保留最近 8 张图片；更早的附件需要重新引用
- 附件仍然在内存文件仓库里，重启服务后旧消息的图会 404
- 没有显式的「参考图清单」面板，用户只能从对话历史里判断哪张是 asset-N
