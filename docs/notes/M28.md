# M28 · 生图切换 Seedream 4.5 + 可切换的生成渠道

日期：2026-11-16
关联：`apps/server/src/features/generation/`、`docs/specs/generation-providers.md`

## 背景

生图额度快用完，需要把默认生图模型切到 `doubao-seedream-4-5-251128`；同时不能把模型写死在工具和 worker 里，客户后续可能换图片/视频供应商，Lavart 的做法是「统一注册表 + 每厂商一个适配器 + 模型元数据 + 按 key 条件注册」，不是每个模型一份业务代码。

## 实现

1. 新增 `providers/registry.ts`
   - `ImageProvider` / `VideoProvider` 统一接口；
   - 注册、按模型找渠道、按展示名找模型 id；
   - `getAvailableImageModels()` / `getAvailableVideoModels()` 返回带 `provider` 的模型目录。
2. 新增 `providers/register-all.ts`
   - 有 `ARK_API_KEY`（兼容旧 `VOLCES_API_KEY`）才注册火山图片；
   - 有 `METASO_API_KEY` 才注册 Metaso 视频；
   - 没 key 的渠道不出现在模型目录里，避免选择必失败模型。
3. 新增 `generation/index.ts`
   - `generateImage` / `generateVideo` 业务层唯一入口；worker 和 Agent 工具不再直接 import 厂商文件；
   - `IMAGE_MODEL` / `VIDEO_MODEL` 控制默认模型，`IMAGE_PROVIDER` / `VIDEO_PROVIDER` 可选；
   - `getGenerationConfig()` + `GET /generation/models` 返回模型目录，供后续后台/前端选择器使用（不含 key）。
4. 火山图片适配器支持两种 size 模式：
   - Seedream 4.5：`size:"2K"/"4K"`，按官方文档在 prompt 里补充「严格按 1:1/16:9 画幅构图」；
   - Seedream 5.0 Lite / 4.0：继续保持显式 WxH。
5. 视频适配器把 MiniMax H3/Highspeed/Lite/Max 的时长、首尾帧、最大参考图写进模型元数据；未知 env 模型也能注册为自定义条目。
6. 业务产物不再写死 `Seedream 5.0 Lite` / `MiniMax H3`，使用结果里的 `modelDisplayName`。

## 配置

```env
ARK_API_KEY=...                 # 优先；VOLCES_API_KEY 继续兼容
IMAGE_MODEL=doubao-seedream-4-5-251128
IMAGE_QUALITY=hd                # 4.5 只支持 2K/4K；standard 会自动升到 2K
ARK_IMAGE_WATERMARK=false

METASO_API_KEY=...
VIDEO_MODEL=MiniMax-H3
VIDEO_RESOLUTION=720p
```

需要切换到其他已注册模型时，只改 `IMAGE_MODEL` / `VIDEO_MODEL` 重启即可；同一模型多渠道时用 `IMAGE_PROVIDER` / `VIDEO_PROVIDER` 指定。Agent 工具也增加了可选 `model` / `quality` / `resolution`，只在用户明确指定时传。

## 真实验证

- `doubao-seedream-4-5-251128` 连续两次真实出图成功：
  - 2K 1:1 → 2048×2048，12s；
  - 2K 1:1 复测 → 2048×2048。
  - 图片保存在 `verification/seedream-4-5-2026-11-16/`（gitignored）。
- 第一次未写画幅指令时输出 4:3，确认「方式 1 必须在 prompt 里说画幅」后补了 `withAspectInstruction`，复测为 1:1。
- `pnpm --filter @my-lovart/server verify:generation-config`：11/11。

## 注意

- Seedream 4.5 的 `size` 方式 1 只有 `2K` / `4K`，不要传 `1K`；`standard` 档会被映射到 2K。
- `verify:generation-config` 不调用模型，只验证注册表、默认值和未知模型拒绝。
- 真正的中转后台（按项目/用户切换模型）还没做；当前是服务端环境变量 + 单次工具参数覆盖。模型目录接口已经预留。
