# M20 · Phase 2b：视频画布与作业进度

## 视频落画布

- `server-canvas.ts` 新增 `insertVideoOnCanvas`：
  - 用 Excalidraw `embeddable` 元素承载视频，`link` 指向 `/files/:id`，`customData` 写 `isVideo/mimeType/durationSeconds/title/assetId`。
  - 尺寸按 560×420 内等比缩放，落位沿用画布写锁 + revision。
  - 不写 canvas files，视频始终走文件路由（支持 Range/206）。
- `worker.ts` 视频作业成功后插画布、回填 `elementId/placement`，和图片走同一套 revision/缓存刷新。
- 前端：
  - `VideoCanvasElement`：悬停静音自动播放、移出暂停、点击切换，播放按钮/Duration 角标，拦截指针事件避免被画布当作拖拽。
  - `CanvasStage` 通过 `renderEmbeddable` 识别 `isVideo`（旧元素用扩展名兜底），`validateEmbeddable` 放行视频 URL。
  - artifact 带 `elementId` → 刷新画布并聚焦；服务端没落画布时客户端 `insertVideo` 兜底插入 embeddable。
- Agent 画布上下文：embeddable 视频显示为「视频」，摘要统计「N 个元素（X 张图片，Y 条视频）」，不再误报“没有图片”。

## 作业进度

- migration `0008_job_progress.sql`（已执行）：`background_jobs.progress int default 0`、`stage text`。
- `updateJobProgress` 只更新 running 作业；成功写 100/完成，重试清零。
- worker：
  - 图片：提交 Seedream 12% → 下载 82% → 落画布 92%。
  - 视频：提交 8% → provider 的排队/渲染进度 → 下载 92% → 落画布 94%。
- 工具 `waitForJob` 每秒轮询，进度变化时推 `tool.progress`，前端工具行显示阶段 + 百分比；`tool.progress` 仍然保留内部 progress/stage 字段。
- 工具超时/取消逻辑不变；取消现在 worker 每 2 秒检查 job 状态，canceled 时 abort provider 请求（Metaso 会顺带 cancelTask），收尾错误不会把 canceled 覆盖成 failed。
