# M7 · 文字与产物交错渲染

## 做了什么

- 助手消息新增有序的 `parts`：文字片段和产物块按到达时间排列，不再固定「所有文字在上、所有图片在下」
- 服务端 `appendDelta` 追加到当前文字片段，`appendBlock` 把非工具块插进序列；工具卡片仍只走运行过程时间线
- 前端收到 `message.delta` / `artifact.ready` 时同步维护 `parts`；ChatPanel 按 parts 渲染，连续且同批次的媒体仍然合成一行
- 老消息没有 `parts` 时自动回退到原来的 `content` + `blocks` 渲染

## 为什么

Video_Remix_Benlai 的执行守则里明确要求流式协议支持「文本→图片→文本→图片」的交错。Agent 做了多步设计时，用户应该看到「先说这一步 → 出图 → 再说下一步 → 再出图」的节奏，而不是最后对着一堆图猜顺序。

## 已知问题

- 只做了渲染顺序，没有给每个文字片段单独复制/引用能力
- 工具卡片仍集中在消息顶部，不参与交错
- Supabase 持久化还没做，`parts` 目前只存在内存里
