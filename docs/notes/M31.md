## 普通用户版回放

用户不按专业术语回答，只说：

1. `我要做一个保温杯的 10 秒广告视频`
2. 被问平台/基调/素材后回答：`发抖音的，竖着拍就行。想要早上出门上班那种感觉，干净一点、别太花。没有杯子照片，就普通白色保温杯、木头盖子，你帮我做吧。`
3. 看到锚图后：`可以，看着挺舒服的。先给我看看第一段画面，视频先别做。`

结果 8/8 通过：

- Agent 从“发抖音/竖着拍”推断 9:16，从“早上出门上班/干净”推断晨间通勤、低饱和；
- 没有实拍，按 adaptive 生成产品设定图和主视觉锚图，并明确说是生成图、不是实物还原；
- 10 秒拆 2 个镜头；第 1 镜首尾帧已生成；
- 没调用 `generate_video`，第 2 镜没有越过视频直接生成。

HTML：`verification/video-conversation-lay-2026-11-16/index.html`。

重跑：`CONVERSATION_SCENARIO=lay pnpm --filter @my-lovart/server run:video-conversation`（默认 pro 场景）。

本轮还补了一条断言：没有把生成设定图说成“和实物一致”。第一次回放出现了这句话，已经加系统提示约束并复测通过。

## Lavart 审计结论

### 会不会主动问用户有没有素材？

**没有结构化机制，也不是系统提示的硬性要求。**

- `apps/server/src/agent/prompts/loomic-main.ts` 只说明 `<input_images>` 是用户上传的参考图，将 asset_id 传给 `generate_image`；
- 主 Agent 工具没有 `offer_choices`/ask-user 工具，只有 `project_search`、`inspect_canvas`、`manipulate_canvas`、`generate_image`、`generate_video`、`persist_sandbox_file`（和可选 brand-kit）；
- 所以它可能在聊天里自然问一句，但不会像我们这样用逐题提问卡把“平台/画幅、基调、有没有实拍”固定成前期必答项。

### 有没有灵感搜索？

**有“灵感发现”首页卡片库，但没有 Agent 内的实时搜索工具。**

- `apps/web/src/components/home-discovery-gallery.tsx` + `home-discovery-library.ts` 从 `home_discovery_categories/cases` 读案例；
- 分类包含“影片与分镜”，点击卡片会把案例变成新项目的起始需求，进入 agent 对话；
- 没有 `search_inspiration` Agent 工具，也没有实时全网搜索。

### 做视频前有哪些步骤？

**Lavart 的 Agent 没有强制的视频前期流程。**

- 系统提示只有“视频（动画、视频片段）→ generate_video”；
- `video-generate.ts` 的 schema 直接收 prompt、model、duration、resolution、aspectRatio、inputImages（最多 7 张，第一张作首帧）；
- 视频面板（`video-generator-panel.tsx`）可选上传首帧/尾帧，时长 4/5/6/8，画幅 16:9/9:16，然后直接出片；
- 没有 canon、角色锚图、分镜镜头、首尾帧血缘、上一镜末帧承接、视频前确认闸门；
- 不会自动生成视觉参考图、角色图或分镜图；
- “分镜故事板”只是 `chat-skills.tsx` 里的一个预设 prompt，用户主动点才会发这句话，不是视频前的自动步骤。

## 我们的差异

| 维度 | Lavart | my-lovart |
| --- | --- | --- |
| 素材 | 用户上传才有，不强制问 | 逐题提问卡会问；无实拍按 adaptive 生成并标注 |
| 灵感 | 首页案例库，非 Agent 工具 | 素材库/灵感 UI；Agent 内实时搜索仍未做 |
| 视频前 | prompt → generate_video；首尾帧可选 | 脚本 → 分镜 → 产品/辅助锚图 → 首尾帧 → 确认 → 出片 → 抽末帧 |
| 一致性 | 无状态机 | canon 血缘、镜头指针、末帧承接、strict/adaptive/loose |
| 自由度 | 更高，适合快速出片 | 更低，适合商业交付；loose 可退回快速草稿 |

## 还没做

- Agent 内真正的灵感搜索（我们目前只有素材库/前端；`search_inspiration` 只在 mock/工具名里，真实 Agent 没有实现）；
- 视频前“角色图”只在有角色时动态生成；本轮保温杯没有角色，属于合理跳过；
- P2 `keyframe_drift` 视觉漂移检测仍未做。
