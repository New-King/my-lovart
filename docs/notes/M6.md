# M6 · Agent 画布操作

## 做了什么

- 新增 `manipulate_canvas` 工具：移动、等比/指定尺寸缩放、删除、按包围盒对齐、均匀分布、前后层、透明度、整体整理；一次最多 8 个动作
- 元素 id 用 `<canvas_state>` 里的真实 id 或 `canvas-1` 别名，服务端先校验再下发，模型编造 id 会被拒绝并提示当前可用元素
- 服务端不直接改 Excalidraw 状态，只发 `canvas.command` 事件；前端用 Excalidraw API 执行并触发原有自动保存，避免服务端和客户端两份场景打架
- 画布摘要从「只列图片」扩成所有可见元素（图片/文字/矩形/箭头…），图片仍然带 `asset_id` 供图生图
- 工具调用显示在运行过程时间线里，标题「调整画布」

## 为什么

Lavart 的 `manipulate_canvas` 让 Agent 能真正整理画布，而不是只会生成图。我们的画布状态在客户端，所以采用「服务端校验命令、客户端执行」的方式，几何逻辑放在纯函数 `canvas-commands.ts`，可以单独测试。

## 已知问题

- 服务端在同一轮里不会同步命令执行后的坐标；连续两次操作如果依赖新位置，需要先让用户下一轮再说
- 删除只过滤元素，不级联清理绑定文字/箭头（当前主要操作对象是图片）
- 还不能由 Agent 新建文字、形状或箭头
