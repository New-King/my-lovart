# M21 · Phase 2.5 分镜与镜头

## 数据

migration `0009_storyboards.sql`（已执行）：

- `storyboards`：title / brief / aspect / style / status / active
- `storyboard_shots`：order_index、标题/描述/prompt、时长/机位/转场、`active_asset_id`、软删除 `deleted_at`
- `storyboard_revisions`：create / reorder / reset / restore 的不可变快照
- `project_assets.shot_id` 补外键；`storyboard_shots.active_asset_id` 补外键（删除资产只清指针）
- 一个项目只会有一个 `active=true` 的分镜：新建或手动 active=true 时，其他分镜自动取消 active

## 仓库

`features/storyboards/storyboards.repository.ts`：

- list（摘要 + 镜头数/ready 数）、get、getShot
- create / updateStoryboard / updateShot / reorder
- deleteShot（软删除）/ resetShot / resetStoryboard / restoreStoryboard
- setShotAsset（版本回退，校验资产属于项目/镜头）
- applyAssetToShot（generation 自动挂当前版本）
- listRevisions

Supabase 不可用时回落内存仓库，工具不会因为迁移缺失直接 500。

## 工具

新增：`list_storyboards`、`get_storyboard`、`create_storyboard`、`update_storyboard`、`update_shot`、`reorder_shots`、`delete_shot`、`reset_shot`、`reset_storyboard`、`restore_storyboard`、`set_shot_asset`。

- `get_storyboard` 返回镜头 + 每镜头最近 6 个版本 + 最近 revisions，便于回退。
- `reset_storyboard` / `delete_shot` 必须 `confirm=true`；false 时返回 `confirmation_required` + 影响范围。
- 生成工具增加 `shotId`；资产记录 `shot_id`，worker/tool 成功后把新资产设为镜头 active，状态 ready。
- 过程行支持所有分镜工具，工具输出摘要（如“3 个镜头”“已切换版本”）。

## 上下文

- 每轮加载分镜：`list` + active 分镜 `get`，构建 `<project_state>`。
- 只展开 active 分镜的全部镜头；其他分镜一行摘要；无分镜时不注入。
- 注入顺序：canvas → project_state → project_assets → input_images。
- trace 记录 storyboardCount / activeStoryboardId / summary。

## 真实模型验证

临时项目，测完删除：

- 上下文：问“这个分镜有几个镜头？第 3 个叫什么？”→ 无工具，直接答对（3 个 / 出门）。
- 改镜头：“把第 3 个镜头机位改成俯拍，先不要生成”→ `get_storyboard` + `update_shot`，DB 机位正确。
- 版本回退：“咖啡广告第 2 个镜头用回第二版”→ `get_storyboard` + `set_shot_asset`，active 切到 v2，v1 保留。
- 两个分镜：“产品开箱第 2 个镜头叫什么”→ 无工具，按 `<project_state>` 答对。
- 重置：第一轮说明影响并等确认（active v1 仍在）；“确认重置”后 `reset_storyboard`，清空 active、状态 draft，资产仍保留，revisions 增加 reset。
- 建分镜：“直接建 3 镜头 9:16 草稿，不生成”→ `create_storyboard`，DB 3 个镜头、时长/机位完整。
- 镜头生成：给第 1 镜头生成 3:4 参考图（真实 Seedream，job 成功）→ `project_assets.shot_id` 正确、shot active 指向新资产且 status=ready、画布元素 assetId 一致。
- server/web typecheck 均 0。
