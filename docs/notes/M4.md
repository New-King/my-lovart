# M4 · 真实图像 / 视频生成

## 做了什么

- Agent 层换成 LangGraph + deepagents：`createDeepAgent` 挂 `generate_image` / `generate_video` / `inspect_canvas` 三个 zod 工具，模型自己决定聊天还是调工具、按什么顺序调
- 接入 Volces Ark 的 Seedream 5.0 Lite 和 Metaso 的 MiniMax H3；工具里直接调 provider、下载结果、落进文件仓库
- 用 `streamEvents` 做适配层：模型文本、工具生命周期、工具执行期间的进度合并成原来的 `RunEvent`，前端协议没变
- 画布摘要和参考图以 asset_id 注入 context，工具按 id 解析成 data URL；画布上的图也能作为图生图输入
- 推理模型的原始 chain-of-thought 不直接展示，用户看到的是模型自己写给用户的计划与结果说明

## 为什么

关键词分流不是 agent。换成框架后，多版本、多工具、连续修改都由模型自己规划；运行时的取消、错误、工具进度仍然走原有的 SSE 契约，不需要改前端。

## 已知问题

- 没有接 checkpointer，刷新后不能从断点恢复
- 生成文件在内存里，进程重启后旧消息的图片会 404
- 视频没有自动放到画布，只在对话里播放
- 没有测试和 CI
