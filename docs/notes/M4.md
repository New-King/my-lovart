# M4 · 真实图像 / 视频生成

## 做了什么

- 接入 Volces Ark 的 Seedream 5.0 Lite（`/images/generations`）和 Metaso 的 MiniMax H3（`/v2/video_generation` + 轮询）
- 保持原有 `RunEvent` 契约：思考、步骤、工具进度、`artifact.ready`、`canvas.sync`、完成/取消/失败都和 mock 一致，前端不用区分模式
- 生成结果先下载进服务端文件仓库，返回稳定的 `/files/:id`，避免供应商 24 小时临时 URL 过期
- 文件路由补了 Range 支持，视频可以拖动进度条
- `GENERATION_MODE=real` 时按关键词/附件分流到生图、生视频或普通聊天；`mock` 仍保留用于无 key 演示

## 为什么

先把「真的能出一张图」打通，比继续打磨假数据重要。事件模型沿用 M3 的完整生命周期，所以接入真实 provider 没有改前端协议，只补了落盘和错误映射。

## 已知问题

- 意图识别还是正则，模型还不能自己决定调哪个工具
- 生成文件在内存里，进程重启后旧消息的图片会 404
- 视频没有自动放到画布，只在对话里播放
- 取消依赖 AbortSignal；图片请求可以断开，视频会尽力调用取消接口
