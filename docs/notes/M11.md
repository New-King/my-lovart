# M11 · 输入框去掉画幅等手动参数

## 做了什么

- Composer 底部只保留左下角「+」和右下角发送/停止按钮
- 删除画幅选择器（3:4 菜单）、`支持拖拽 / 粘贴` 提示、`⏎ 发送` 提示
- 新消息不再向服务端传 `aspectRatio`；画幅由模型根据用途、平台和内容自己决定，写进 `generate_image` / `generate_video` 的参数里
- 开场示例也不再预设 `3:4` / `16:9`，只描述用途和风格

## 为什么

Lavart 的输入框只有模型偏好等入口，没有画幅下拉；画幅是生成工具的参数，不是用户每次都要先选的表单。我们之前把它放在输入框，会让所有请求都被强制带一个 `<aspect_ratio>`，反而覆盖模型的判断。现在默认模型自己选，只有卡片「再生成」会沿用上一张的画幅。

## 已知问题

- 如果用户明确说「要 16:9」，模型需要自己把它翻译成工具参数，没有界面兜底
- 画幅不在输入框展示，用户想看当前选择只能在生成后的卡片信息里看到
